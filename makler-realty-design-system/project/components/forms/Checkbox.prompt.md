# Checkbox

Multi-select control for filter lists (amenities, features) and consent checkboxes.

```jsx
<Checkbox label="Sea view" defaultChecked />
<Checkbox label="Parking" />
<Checkbox label="Select all" indeterminate />
<Checkbox label="I agree to be contacted" />
```

- Wraps a native checkbox — pass `checked`/`defaultChecked`/`onChange`.
- `indeterminate` shows the mixed state for "select all" rows.
