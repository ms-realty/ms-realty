# Hero image attribution

The following locally hosted responsive derivatives are resized and re-encoded for the MS Realty hero gallery. The Sandanski derivatives also use a 16:9 crop that removes the original image's right-side building. No user-provided source image was replaced or discarded; those sources remain the mobile `<picture>` candidates.
